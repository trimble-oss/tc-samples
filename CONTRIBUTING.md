# Contributing to Trimble Connect .NET SDK Samples

To start contributing to Trimble OSS and ensure that you've been added to the organization [please read through our quickstart instructions.](https://trimble-oss.github.io/contribute/#getting-started)

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your changes
4. Make your changes
5. Test your changes
6. Submit a pull request

## Development Environment

* Visual Studio 2017 or later

## Code Style

Please follow the existing code style and conventions used in this project.

## Questions?

If you have questions, please reach out to the maintainers or visit the [Trimble Connect Developer Portal](https://developer.trimble.com/docs/connect).

## Support

See https://developer.trimble.com/docs/connect#support-and-community.
